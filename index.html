Hiring

我的团队正在招聘对运动健康+大模型感兴趣的同学一起做研究，欢迎加入。

AI 产品经理 / 实习生

招聘中 Keep · 北京 望京 · 全职 / 实习

职位描述

  1. 探索 AIGC / AGI 技术在健康运动领域的应用，打造 Keep AI 智能教练，提升用户的健康与运动体验。
  2. 利用大模型技术，结合各种 Agent 框架，打造 AI 智能对话助手，通过 LUI 打造新的分发交互模式。
  3. 利用大模型技术，结合用户的健康需求，研发端到端健康大模型，打造 AI Native 的健康智能助手。
  4. 挖掘和发现关键问题，调研各种大模型的能力，有效协同各方资源，推进策略落地，达成业务目标。

职位要求

  1. 我们有现场 coding，产品经理为什么要 coding？因为我们是 AI Native 产品。考察 SQL + Python 基础，以及传统机器学习相关知识。
  2. 本科及以上学历，熟悉常用的机器学习算法，深度掌握大模型底层原理——知道大模型是如何学习知识、如何推理生成。
  3. 有想法且有能力自己开发各种 Agent，能用框架做微调。比如你不能只听过 LangGraph，你得能用它快速搭建 ReAct 类的 Agent。
  4. 大模型现在有一堆坑，尤其是 MAS：意图怎么更准确，记忆怎么更持久，推理怎么更合理，业务逻辑怎么更简单地理解，工程能力怎么高效复用——不讲概念，能讲经验。
  5. 具备良好的数据分析能力，SQL + 各种分析框架是基本功。幸存者偏差、辛普森悖论、威尔逊区间，你不光知道公式，也知道业务里哪儿会用到。
  6. 数学好的同学优先，最好对运筹规划、机器学习底层优化算法、建模有深度研究。
  7. 对这件事有真实的兴趣和想法，不光想着把事情做完，还非常想把事情做成——认为人这一辈子，做成一件事情，很重要。
  8. 热爱运动当然好；如果还进一步学习了运动生理学——知道运动有什么用、身体如何供能、神经如何调节、超量恢复是什么那就更好。
